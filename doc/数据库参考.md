## 📋 数据库概述

| 配置项 | 值 |
|--------|-----|
| 数据库类型 | PostgreSQL 15 |
| 数据库名 | `asset_catalog` |
| 连接端口 | 5432 |

**进入数据库命令行**：
```bash
docker exec -it asset_catalog_db psql -U admin -d asset_catalog
```

## 一、核心公共表

### 1.1 asset_catalog（资产目录表）

所有业务资产的核心表，存储文件物理属性和基础标签。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGSERIAL | 主键 |
| `filepath` | VARCHAR | NAS文件完整路径（唯一） |
| `filename` | VARCHAR(512) | 文件名 |
| `file_size` | BIGINT | 文件大小(字节) |
| `file_extension` | VARCHAR(20) | 文件扩展名 |
| `file_mtime` | TIMESTAMP | 文件修改时间 |
| `file_hash` | VARCHAR(64) | 文件MD5哈希 |
| `category` | VARCHAR(100) | 分类路径 |
| `year` | INTEGER | 年份 |
| `quarter` | VARCHAR(10) | 季度 |
| `status` | VARCHAR(20) | 状态(ready/pending/archived) |

**索引**：`filepath`(唯一), `category`, `year`, `quarter`

## 二、应急安全模块

### 2.1 emergency_alarm_assets（告警图片资产表）

存储应急安全告警图片及其业务数据。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGSERIAL | 主键 |
| `asset_id` | BIGINT | 关联 asset_catalog.id |
| `alarm_id` | INTEGER | 原始告警ID |
| `alarm_type` | INTEGER | 告警类型: 400/401/402 |
| `alarm_name` | VARCHAR(32) | 告警名称 |
| `dev_code` | VARCHAR(64) | 设备编码 |
| `alarm_time` | TIMESTAMP | 告警时间 |
| `analysis` | TEXT | AI分析结果 |
| `quarter` | VARCHAR(10) | 季度 |

**告警类型对照**：
| 类型码 | 名称 |
|--------|------|
| 400 | 森林防火 |
| 401 | 烟雾检测报警事件 |
| 402 | 热成像报警事件 |

## 五、常用查询SQL示例

### 应急模块 - 按告警类型搜索

```sql
SELECT
    a.id,
    a.filename,
    a.filepath,
    e.alarm_name,
    e.alarm_time,
    e.dev_code,
    e.analysis
FROM asset_catalog a
JOIN emergency_alarm_assets e ON a.id = e.asset_id
WHERE e.alarm_name LIKE '%火点检测%'
  AND a.status = 'ready'
ORDER BY e.alarm_time DESC
LIMIT 20;
```

### 应急模块 - 时间范围查询

```sql
SELECT
    a.filename,
    e.alarm_name,
    e.alarm_time
FROM asset_catalog a
JOIN emergency_alarm_assets e ON a.id = e.asset_id
WHERE e.alarm_time BETWEEN '2025-10-01' AND '2025-12-31'
ORDER BY e.alarm_time DESC;
```

### 法院模块 - 按法院统计

```sql
SELECT 
    fymc as 法院名称, 
    COUNT(*) as 案件数 
FROM court_cases 
GROUP BY fymc 
ORDER BY COUNT(*) DESC;
```

### 法院模块 - 按分类统计卷宗

```sql
SELECT 
    classify as 分类, 
    COUNT(*) as 卷宗数 
FROM court_dossiers 
GROUP BY classify 
ORDER BY COUNT(*) DESC;
```

### 统计查询

```sql
-- 资产总数
SELECT COUNT(*) FROM asset_catalog WHERE status = 'ready';

-- 告警记录总数
SELECT COUNT(*) FROM emergency_alarm_assets;

-- 法院案件总数
SELECT COUNT(*) FROM court_cases;

-- 法院卷宗总数
SELECT COUNT(*) FROM court_dossiers;
```

## 六、数据库维护

### 备份数据库

```bash
# 完整备份
docker exec -T asset_catalog_db pg_dump -U admin asset_catalog > backup_$(date +%Y%m%d).sql

# 仅备份结构
docker exec -T asset_catalog_db pg_dump -U admin --schema-only asset_catalog > schema_backup.sql
```

### 恢复数据库

```bash
docker exec -i asset_catalog_db psql -U admin -d asset_catalog < backup_file.sql
```

### 性能优化

```bash
# 重建索引
docker exec -i asset_catalog_db psql -U admin -d asset_catalog -c "REINDEX DATABASE asset_catalog;"

# 分析表统计
docker exec -i asset_catalog_db psql -U admin -d asset_catalog -c "ANALYZE;"
```
