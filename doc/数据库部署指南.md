## 🔍 常用查询示例

### 1. 通过视图查询（推荐）

```sql
-- 查询2024年所有森林防火告�?
SELECT 
    alarm_id,
    alarm_name,
    alarm_time,
    dev_name,
    area_name,
    filepath
FROM v_alarm_assets_full
WHERE alarm_time >= '2024-01-01'
  AND alarm_type = 400
ORDER BY alarm_time DESC
LIMIT 100;
```

### 2. JSONB字段查询

```sql
-- 查询特定设备的告�?
SELECT 
    alarm_id,
    alarm_time,
    business_data->>'dev_code' AS dev_code,
    business_data->>'dev_name' AS dev_name
FROM emergency_alarm_assets
WHERE business_data->>'dev_code' = 'DEV001';

-- 查询包含AI分析结果的告�?
SELECT 
    alarm_id,
    business_data->>'analysis' AS analysis
FROM emergency_alarm_assets
WHERE business_data ? 'analysis'
  AND business_data->>'analysis' IS NOT NULL;
```

### 3. 统计查询

```sql
-- 按区域统计告警数�?
SELECT 
    area_code,
    COUNT(*) AS total_alarms,
    COUNT(*) FILTER (WHERE status = 1) AS pending,
    COUNT(*) FILTER (WHERE status = 2) AS processed
FROM emergency_alarm_assets
GROUP BY area_code
ORDER BY total_alarms DESC;

-- 查看每日扫描任务统计
SELECT * FROM v_scan_tasks_summary
ORDER BY scan_date DESC
LIMIT 7;
```

### 4. 文件操作审计

```sql
-- 查看最近的文件操作
SELECT 
    operation_type,
    filepath_new,
    operated_by,
    operated_at,
    status
FROM file_operation_log
ORDER BY operated_at DESC
LIMIT 20;

-- 统计各类操作数量
SELECT 
    operation_type,
    COUNT(*) AS total,
    COUNT(*) FILTER (WHERE status = 'success') AS success,
    COUNT(*) FILTER (WHERE status = 'failed') AS failed
FROM file_operation_log
WHERE operated_at >= CURRENT_DATE - INTERVAL '7 days'
GROUP BY operation_type;
```

## 📈 性能优化

### 查看索引使用情况

```sql
-- 查看表大�?
SELECT 
    schemaname,
    tablename,
    pg_size_pretty(pg_total_relation_size(schemaname||'.'||tablename)) AS size
FROM pg_tables
WHERE schemaname = 'public'
ORDER BY pg_total_relation_size(schemaname||'.'||tablename) DESC;

-- 查看索引使用情况
SELECT 
    schemaname,
    tablename,
    indexname,
    idx_scan AS index_scans
FROM pg_stat_user_indexes
ORDER BY idx_scan DESC;
```
