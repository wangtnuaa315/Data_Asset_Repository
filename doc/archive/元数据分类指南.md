## 🔄 从MySQL导出metadata_emergency.csv

### 方法1：SQL导出

```sql
SELECT 
    CONCAT('alarm_', DEV_CODE, '.png') as filename,
    ALARM_NAME as alarm_name,
    JSON_UNQUOTE(JSON_EXTRACT(analysis, '$.result')) as analysis_result,
    DATE_FORMAT(ALARM_TIME, '%Y-%m-%d %H:%i:%s') as alarm_time,
    DEV_CODE as device_code
FROM vp_hk_alarm
WHERE ALARM_TIME >= '2025-12-01'
INTO OUTFILE '/tmp/metadata_emergency.csv'
FIELDS TERMINATED BY ','
ENCLOSED BY '"'
LINES TERMINATED BY '\n';
```

### 方法2：Python脚本导出

```python
import pymysql
import csv

conn = pymysql.connect(
    host='192.168.2.170',
    user='root',
    password='your_password',
    database='ia_center'
)

cursor = conn.cursor()
cursor.execute("""
    SELECT 
        CONCAT('alarm_', DEV_CODE, '.png') as filename,
        ALARM_NAME,
        JSON_UNQUOTE(JSON_EXTRACT(analysis, '$.result')),
        ALARM_TIME,
        DEV_CODE
    FROM vp_hk_alarm
    WHERE ALARM_TIME >= '2025-12-01'
""")

with open('metadata_emergency.csv', 'w', newline='', encoding='utf-8') as f:
    writer = csv.writer(f)
    writer.writerow(['filename', 'alarm_name', 'analysis_result', 'alarm_time', 'device_code'])
    writer.writerows(cursor.fetchall())
```
