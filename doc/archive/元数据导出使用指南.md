### 步骤2：添加文件名提取方法（如果需要）

```python

    """从你的字段提取文件名"""
    your_field = row.get('your_filename_field', '')
    
    # 提取逻辑
    filename = os.path.basename(your_field)
    
    # 确保格式
    if not filename.startswith('alarm_'):
        filename = f"alarm_{filename}"
    
    return filename
```
