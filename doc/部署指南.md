## 📋 系统概述

### 服务地址

| 服务名称 | 端口 | 访问地址 | 用途 |
|---------|------|---------|------|
| **资产检索前端** | 8082 | http://192.168.2.170:8082 | 资产检索主界面 |
| **资产检索后端** | 8003 | http://192.168.2.170:8003/docs | API接口文档 |
| PostgreSQL | 5432 | 内部访问 | 资产元数据存储 |
| pgAdmin 4 | 18080 | http://192.168.2.170:18080 | 数据库管理界面 |
| FileBrowser | 8081 | http://192.168.2.170:8081 | 文件管理界面 |

### 技术栈

- **后端**: FastAPI + asyncpg + Pydantic
- **前端**: Vue 3 + Element Plus + Vite
- **数据库**: PostgreSQL 15
- **部署**: Docker Compose

## 🚀 快速部署

### 1. 上传代码到服务器

```bash
# 使用 SFTP 上传
sftp root@192.168.2.170
cd /opt/data_asset
put -r asset-web-backend
put -r asset-web-frontend
put docker-compose.yml
```

### 2. 启动所有服务

```bash
cd /opt/data_asset
docker-compose up -d
```

### 3. 验证部署

```bash
# 检查容器状态
docker-compose ps

# 检查各服务日志
docker logs asset_web_api --tail 20
docker logs asset_web_ui --tail 20
```

## 🔧 服务管理

### 查看服务状态
```bash
docker-compose ps
```

### 启动/停止服务
```bash
# 启动所有服务
docker-compose up -d

# 停止所有服务
docker-compose down

# 重启单个服务
docker-compose restart asset_web_api
docker-compose restart asset_web_ui
```

### 重新构建服务
```bash
# 重新构建后端
docker-compose build --no-cache asset_web_backend && docker-compose up -d asset_web_backend

# 重新构建前端
docker-compose build --no-cache asset_web_frontend && docker-compose up -d asset_web_frontend
```

### 查看日志
```bash
# 查看后端日志
docker logs asset_web_api --tail 100

# 查看前端日志
docker logs asset_web_ui --tail 100

# 实时查看日志
docker logs -f asset_web_api
```
