## 一、工作流程

```
1. 从MySQL导出告警数据 → metadata_emergency.csv
2. 重命名图片为 alarm_设备编码.png
3. 上传图片 + metadata_emergency.csv 到 new_uploads/
4. 运行脚本自动分类并入库
```

---

## 二、metadata_emergency.csv 格式

### 必需字段

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `filename` | 文件名 | `alarm_001e67b2f0411310030522.png` |
| `alarm_name` | 告警名称（用于分类） | `烟雾检测` |

### 可选字段

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `alarm_time` | 告警时间 | `2025-12-01 09:38:16` |
| `analysis_result` | AI分析结果 | `误报(自然雾气)` |
| `device_code` | 设备编码 | `001e67b2f0411310030522` |
| `alarm_id` | 原始告警ID | `12345` |
| `alarm_type` | 告警类型码 | `400` |

### 示例文件

```csv
filename,alarm_name,analysis_result,alarm_time,device_code
alarm_001.jpg,火点检测报警事件,检测到疑似火情,2025-10-15 14:30:00,DEV001
alarm_002.png,烟雾检测报警事件,误报(自然雾气),2025-10-16 08:45:00,DEV002
```

## 三、元数据导出工具

### 1. 查看可用场景

```bash
cd /opt/data_asset
python scripts/emergency/export_metadata.py --list
```

输出示例：
```
可用的导出场景：
场景名称: emergency_hk_alarm
  描述: 应急海康设备告警（二次分析）
  数据表: vp_hk_alarm

场景名称: emergency_ai_alarm
  描述: 应急AI设备告警
  数据表: vp_ai_device_alarm
```

### 2. 导出元数据

```bash
# 导出应急海康告警（最近一个月）
python scripts/emergency/export_metadata.py \
  --scene emergency_hk_alarm \
  --days 30 \
  --output metadata_emergency.csv

# 导出AI设备告警（指定日期范围）
python scripts/emergency/export_metadata.py \
  --scene emergency_ai_alarm \
  --start-date 2025-10-01 \
  --end-date 2025-12-31 \
  --output metadata_emergency.csv
```

## 四、数据导入流程

### 步骤1：准备数据

1. 将图片上传到 `00_Work_Area/new_uploads/`
2. 将 `metadata_emergency.csv` 放在同一目录

### 步骤2：执行处理脚本

```bash
cd /opt/data_asset
source venv/bin/activate

# 1. 验证文件结构并分类
python scripts/emergency/verify_structure.py

# 2. 注册到资产目录
python scripts/common/register_assets.py

# 3. 导入业务数据
python scripts/emergency/import_from_csv.py
```

### 步骤3：验证导入结果

```bash
docker exec -it asset_catalog_db psql -U admin -d asset_catalog -c "
SELECT COUNT(*) as 资产数 FROM asset_catalog WHERE status = 'ready';
SELECT COUNT(*) as 告警数 FROM emergency_alarm_assets;
SELECT alarm_name as 告警类型, COUNT(*) as 数量 FROM emergency_alarm_assets GROUP BY alarm_name;
"
```

## 五、分类规则

### 告警类型自动分类

文件会根据 `metadata_emergency.csv` 中的 `alarm_name` 字段自动分类到目录：

```
10_Official_Library/
└── 02_应急安全/
    └── 02_历史告警归档/
        ├── 火点检测报警事件/
        │   └── 2025_Q4/
        ├── 烟雾检测报警事件/
        │   └── 2025_Q4/
        └── 热成像报警事件/
            └── 2025_Q4/
```

### 名称映射

| CSV中的 alarm_name | 分类目录 |
|-------------------|----------|
| 火点检测 / 火点检测报警事件 | 火点检测报警事件 |
| 烟雾检测 / 烟雾报警 | 烟雾检测报警事件 |
| 热成像 / 热成像报警 | 热成像报警事件 |

## 六、批量处理技巧

### 后台运行大量文件

```bash
nohup python scripts/emergency/verify_structure.py > verify.log 2>&1 &
tail -f verify.log
```

### 一次性执行所有步骤

```bash
cd /opt/data_asset
source venv/bin/activate

python scripts/emergency/verify_structure.py && \
python scripts/common/register_assets.py && \
python scripts/emergency/import_from_csv.py
```

## 七、故障排查

### 问题1：找不到对应的分类

检查 `metadata_emergency.csv` 中的 `alarm_name` 是否包含有效的告警类型关键词。

### 问题2：文件未被移动

检查文件是否已在目标目录，脚本会跳过已存在的文件。

### 问题3：导入数据为0

确认 `metadata_emergency.csv` 的 `filename` 字段与实际图片文件名一致。
