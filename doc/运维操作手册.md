# 数据资产检索系统 - 运维操作手册

## 📋 系统概述

| 模块 | 端口 | 容器名 |
|------|------|--------|
| 前端 | 8082 | asset_web_ui |
| 后端 API | 8003 | asset_web_api |
| PostgreSQL | 5432 | asset_catalog_db |
| PgAdmin | 18080 | asset_catalog_pgadmin |
| 文件管理 | 8081 | asset_file_manager |

---

## 🚀 服务管理

### 启动所有服务
```bash
cd /opt/data_asset
docker-compose up -d
```

### 停止所有服务
```bash
cd /opt/data_asset
docker-compose down
```

### 重启单个服务
```bash
# 重启后端
docker restart asset_web_api

# 重启前端
docker restart asset_web_ui

# 重启数据库（谨慎）
docker restart asset_catalog_db
```

### 查看服务状态
```bash
docker ps -a | grep asset
```

### 查看日志
```bash
# 后端日志
docker logs asset_web_api --tail 100 -f

# 前端日志
docker logs asset_web_ui --tail 100 -f

# 数据库日志
docker logs asset_catalog_db --tail 100 -f
```

## 🔄 代码更新部署

```bash

docker-compose up -d asset_web_backend
```

```bash
docker-compose up -d asset_web_frontend
```

## 🗄️ 数据库操作

### 进入数据库命令行
```bash
docker exec -it asset_catalog_db psql -U admin -d asset_catalog
```

### 执行 SQL 脚本
```bash
docker exec -i asset_catalog_db psql -U admin -d asset_catalog < script.sql
```

### 备份数据库
```bash
docker exec asset_catalog_db pg_dump -U admin asset_catalog > backup_$(date +%Y%m%d).sql
```

### 恢复数据库
```bash
docker exec -i asset_catalog_db psql -U admin -d asset_catalog < backup_20260120.sql
```

### 查看表记录数
```bash
docker exec -i asset_catalog_db psql -U admin -d asset_catalog -c "
SELECT 'emergency_alarm_assets' as table_name, COUNT(*) FROM emergency_alarm_assets
UNION ALL
SELECT 'legal_documents', COUNT(*) FROM legal_documents
UNION ALL
SELECT 'court_cases', COUNT(*) FROM court_cases;
"
```

## 📥 数据导入

### 法律文书模块

#### 工作流程
```
1. 通过 FileBrowser 上传 Excel → 00_Work_Area/new_uploads/
2. 运行导入脚本 → 数据入库 + 文件移动到归档目录
3. 归档目录: 10_Official_Library--01_法院_司法/法院文书/
```

#### 1. 导入案由分类树（一次性）
```bash
cd /opt/data_asset
python3 scripts/legal/import_cause_tree.py
```

#### 2. 上传 Excel 文件
- 方式一：FileBrowser（推荐）
  1. 访问 http://192.168.2.170:8081/files/
  2. 导航到 `00_Work_Area/new_uploads/`
  3. 上传 Excel 文件

- 方式二：命令行
```bash
scp /local/path/*.xlsx root@192.168.2.170:/data/nas_data/00_Work_Area/new_uploads/
```

#### 3. 执行导入
```bash
cd /opt/data_asset

# 预览模式（检查文件，不导入）
python3 scripts/legal/import_legal_documents.py --dry-run

# 正式导入
python3 scripts/legal/import_legal_documents.py

# 大量文件时后台运行
nohup python3 scripts/legal/import_legal_documents.py > import_legal.log 2>&1 &
tail -f import_legal.log
```

#### 4. 验证导入结果
```bash
docker exec -i asset_catalog_db psql -U admin -d asset_catalog -c "
SELECT COUNT(*) as total_docs FROM legal_documents;
SELECT case_type, COUNT(*) FROM legal_documents GROUP BY case_type;
"
```

### 法院卷宗模块

#### 工作流程
```
1. 通过 FileBrowser 或 SCP 上传案件文件夹 → 00_Work_Area/new_uploads/{城市名}/
2. 激活虚拟环境后运行对应城市的导入脚本
3. 脚本自动解压 ZIP/RAR/7z → 分类识别 → 数据入库 → 文件归档
```

#### 1. 上传案件文件

**上传方式**：
- 方式一：FileBrowser（推荐）
  1. 访问 http://192.168.2.170:8081/files/
  2. 导航到 `00_Work_Area/new_uploads/{城市名}/`
  3. 上传案件文件夹或压缩包

- 方式二：命令行
```bash
scp -r /本地路径/案件文件 root@192.168.2.170:/data/nas_data/00_Work_Area/new_uploads/{城市名}/
```

#### 2. 执行导入

**通用命令模板**：
```bash
cd /opt/data_asset
source env/bin/activate

# 预览模式（查看会导入什么，不实际执行）
python3 scripts/court/import_{城市}_dossiers.py --source /data/nas_data/00_Work_Area/new_uploads/{城市名} --dry-run

# 正式导入
python3 scripts/court/import_{城市}_dossiers.py --source /data/nas_data/00_Work_Area/new_uploads/{城市名}
```

**各城市导入脚本**：

| 城市 | 脚本名 | 法院代码 | 示例命令 |
|------|--------|----------|----------|
| 东台 | import_dongtai_dossiers.py | 0981 | `--source .../东台` |
| 建邺 | import_jianye_dossiers.py | 0105 | `--source .../建邺` |
| 江都 | import_jiangdu_dossiers.py | 1012 | `--source .../江都` |
| 南通 | import_nantong_dossiers.py | 0602/0612/0613 | `--source .../南通` |
| 天宁 | import_tianning_dossiers.py | 0402 | `--source .../天宁` |
| 无锡 | import_wuxi_dossiers.py | 02/0211 | `--source .../无锡` |
| 徐州 | import_xuzhou_dossiers.py | 0311 | `--source .../徐州` |
| 佛山 | import_foshan_dossiers.py | 粤06 | `--source .../佛山` |

**后台运行大量文件**：
```bash
nohup python3 scripts/court/import_{城市}_dossiers.py --source /path/to/source > import_{城市}.log 2>&1 &
tail -f import_{城市}.log
```

#### 3. 支持的压缩格式

| 格式 | 需安装 |
|------|--------|
| ZIP | 无需额外安装 |
| RAR | `apt install unrar` |
| 7z | `apt install p7zip-full` |

#### 4. 分类规则对照表

| 分类 | 目录名匹配 | 文件名匹配 |
|------|------------|------------|
| 起诉状 | `起诉状/`、`诉状/` | 起诉状、诉状 |
| 答辩状 | `答辩状/` | 答辩状、答辩 |
| 证据 | `证据/` | 证据、合同、借款、凭证 |
| 庭审笔录 | `笔录/`、`庭审笔录/` | 庭审笔录、开庭笔录、听证笔录 |
| 判决书 | `判决书/`、`原审材料/` | 判决书、判决 |
| 立案审批表 | `立案/`、`立案登记表/` | 立案审批、立案登记 |
| 送达回证 | `送达回证/` | 送达回证、快递单 |
| 上诉状 | - | 上诉状、上诉 |
| 其他文件 | - | 未匹配时的默认分类 |

#### 5. 验证导入结果
```bash
docker exec -i asset_catalog_db psql -U admin -d asset_catalog -c "
SELECT fymc as 法院, COUNT(*) as 案件数 FROM court_cases GROUP BY fymc ORDER BY COUNT(*) DESC;
SELECT classify as 分类, COUNT(*) as 卷宗数 FROM court_dossiers GROUP BY classify ORDER BY COUNT(*) DESC;
"
```

## 🔧 故障排查

### 后端无法启动
```bash
# 1. 查看详细日志
docker logs asset_web_api --tail 100

# 2. 常见问题
# - 数据库连接失败：检查 asset_catalog_db 是否运行
# - 模块导入失败：检查 Python 依赖是否完整
```

### 前端白屏/404
```bash
# 1. 检查 dist 是否存在
ls -la /opt/data_asset/asset-web-frontend/dist/

# 2. 重新构建
cd /opt/data_asset/asset-web-frontend
rm -rf dist
npm run build

# 3. 重建镜像
cd /opt/data_asset
docker-compose build asset_web_frontend
docker-compose up -d asset_web_frontend
```

### API 返回 404
```bash
# 检查路由是否注册
curl http://localhost:8003/docs  # 查看 Swagger 文档
```

### 数据库连接失败
```bash
# 1. 检查数据库容器
docker ps | grep asset_catalog_db

# 2. 检查端口
netstat -tlnp | grep 5432

# 3. 测试连接
docker exec -it asset_catalog_db psql -U admin -d asset_catalog -c "SELECT 1;"
```
